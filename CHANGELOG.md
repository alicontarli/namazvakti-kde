# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-07-19

### Added
- Initial porting from Namaz Vakti GNOME to KDE Plasma 6.
- Saf QML/JS applet implementation with versionless imports compatibility.
- Settings configuration backend using KConfig xml definitions.
- Local cache engine utilizing QtQuick.LocalStorage (SQLite) database.
- Asynchronous AlAdhan API monthly calendar fetches.
- Real-time language switching engine supporting 11 locales.
- Single-line panel layout for horizontal panels and wrapped two-line layout for vertical panels.
- Automated testing suite covering 24 target computation scenarios.
