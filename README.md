# Namaz Vakti KDE

A simple, lightweight, and modern KDE Plasma 6 plasmoid (panel applet) that displays the next Islamic prayer time and its remaining countdown directly in the system status area.

This project is the KDE Plasma 6 port of the **Namaz Vakti GNOME** extension, rebuilt from scratch as a native Plasma applet.

## Features

*   **Panel Indicator:** Displays the next prayer time and countdown cleanly (e.g. `Asr · 00:58` or `00:58`). Automatically wraps to two lines on vertical panels to prevent horizontal clipping.
*   **Comprehensive Tooltip:** Hovering over the indicator reveals a detailed overview of the location, target prayer time, and remaining duration.
*   **Interactive Popup Menu:** Displays daily prayer times (with the active prayer highlighted), location details, a manual refresh button, and a settings shortcut.
*   **Multilingual Support (11 Languages):** Fully translated out of the box with real-time UI switching (no plasmashell restart required):
    *   English (default fallback)
    *   Turkish (Türkçe)
    *   Arabic (العربية)
    *   Bengali (বাংলা)
    *   Spanish (Español)
    *   French (Français)
    *   German (Deutsch)
    *   Russian (Русский)
    *   Persian (فارسی)
    *   Urdu (اردو)
    *   Indonesian (Bahasa Indonesia)
*   **Offline Mode & Cache:** Automatically downloads and caches monthly calendars from the AlAdhan API. Utilizing `QtQuick.LocalStorage` (SQLite), the applet remains fully operational even if the internet connection is temporarily lost.
*   **Manual Minute Adjustments:** Allows adjusting prayer calculations by `-30` to `+30` minutes per prayer to match local mosque timetables.
*   **Customizable Preferences:** Configurable location options (city/country search or coordinates), calculation methods (e.g., Diyanet, Muslim World League, Umm al-Qura), jurisprudence schools (Standard/Hanafi), notification options, and layout toggles.

## Requirements

*   KDE Plasma 6 (specifically tested on Plasma 6.7.2)
*   Qt 6
*   `kpackagetool6` (for installation)

## Local Installation

To install the plasmoid manually on your system:

### 1. Install/Update Applet
Run the installation script which registers the plasmoid to `~/.local/share/plasma/plasmoids/com.local.namazvakti/`:
```bash
./scripts/install-local.sh
```

### 2. Add to Panel
Right-click on your Plasma panel, select **Add Widgets...**, find **Namaz Vakti KDE**, and drag it onto your panel.

### 3. Uninstall
To remove the plasmoid from your system:
```bash
./scripts/uninstall-local.sh
```

## Development & Testing

### Running Tests
Run the unit test suite covering date boundaries, rollovers, formatting, and translations:
```bash
./scripts/test.sh
```

### Packaging
To build the distributable `.plasmoid` and `.zip` archives, run:
```bash
./scripts/package.sh
```
The output files will be created in the `dist/` directory:
*   `dist/namaz-vakti-kde-1.0.0.plasmoid`
*   `dist/namaz-vakti-kde-1.0.0.zip`

## Troubleshooting & Logs
To inspect the runtime logs and debug outputs generated by the plasmoid, run:
```bash
journalctl --user -f | grep -i NamazVaktiKDE
```
